RIO VICTORIA - PAQUETE PARA GITHUB PAGES

Archivos:
- index.html: aplicación web, consulta directa a la API oficial del INA.
- manifest.webmanifest: configuración para instalar como acceso directo/app web.
- sw.js: service worker para caché básica y actualización de archivos.

Configuración utilizada:
- Estación: Victoria – Prefectura Naval Argentina.
- Tipo de serie: puntual.
- Serie INA: 32 (dato de trabajo acordado previamente).
- Endpoint: https://alerta.ina.gov.ar/a5/obs/puntual/series/32/observaciones
- Umbrales informativos: alerta 4,60 m; evacuación 5,90 m.

IMPORTANTE:
La API está documentada por el INA, pero el acceso directo desde GitHub Pages debe probarse en un navegador real. Si el navegador informa CORS, no se debe mostrar una altura inventada ni guardada como si fuera actual: habrá que incorporar un proxy HTTPS intermedio. El paquete informa ese error y ofrece abrir el visor oficial.

Para publicar: subir los tres archivos a la raíz del repositorio de GitHub Pages y aceptar reemplazar los existentes. Luego abrir la página y tocar “Actualizar medición”.
